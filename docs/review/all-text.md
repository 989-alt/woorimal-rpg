## 마무리 퀴즈

낱말 50개 가운데 10개를 무작위로 골라 뜻 고르기 4문제, 초성 3문제, 상황 빈칸 3문제를 섞어 냅니다. 하트·시간 제한은 없습니다. 처음 화면의 "마무리 퀴즈" 버튼으로도 다시 풀 수 있습니다(엔딩을 본 저장이 있을 때).

- **뜻 고르기**: "'낱말'의 뜻은?" 보기 넷 가운데 하나는 그 낱말 뜻, 셋은 다른 낱말 뜻입니다.
- **초성**: 초성 글자(예: ㅇㅅㄹ)와 뜻을 보고 낱말을 직접 칩니다.
- **상황 빈칸**: 아래 문장의 빈칸에 들어갈 낱말을 넷 가운데 고릅니다. 오답 보기에는 뜻이 가까운 낱말(맨 아래 묶음)을 넣지 않고, 하나는 다른 막 낱말입니다.

끝나면 "10문제 중 n개 맞힘"과 낱말별 ○/×, 틀린 낱말의 뜻이 나오고 "다시 풀기"·"계속" 버튼이 있습니다.

### 상황 빈칸 문장 (낱말마다 하나, 굵은 글씨가 빈칸에 들어가는 꼴)

**1막 새벽골**

- 어스름: 해가 뜨기 전 ___ 속에서 우유 배달 자전거 소리가 들렸다. → **어스름**
- 아침나절: 아침밥을 먹고 나서 ___ 내내 텃밭의 풀을 뽑았다. → **아침나절**
- 해거름: ___이 되자 서쪽 산에 걸린 해가 마을을 붉게 물들였다. → **해거름**
- 부리나케: 학원 차가 벌써 왔다는 말에 ___ 신발을 신고 뛰어나갔다. → **부리나케**
- 매무새: 발표하러 나가기 전에 옷 ___를 단정하게 고쳤다. → **매무새**
- 짬: 숙제를 하다가 ___이 나서 강아지와 잠깐 놀았다. → **짬**
- 곰비임비: 생일날 친구들의 축하 문자가 ___ 날아들었다. → **곰비임비**
- 얼추: 모둠 그림이 ___ 다 그려져서 색칠만 조금 남았다. → **얼추**
- 손사래: 용돈을 더 주겠다는 삼촌의 말에 누나가 ___를 쳤다. → **손사래**
- 오롯이: 형은 방학 동안 모은 용돈을 한 푼도 쓰지 않고 ___ 저금했다. → **오롯이**

**2막 너울장**

- 들머리: 골목 ___에 있는 빵집에서 고소한 냄새가 풍겨 왔다. → **들머리**
- 마수걸이: 붕어빵 아저씨는 오늘 첫 손님에게 팔아 ___를 했다. → **마수걸이**
- 에누리: 문구점 주인이 천 원을 ___해 주어서 공책을 하나 더 샀다. → **에누리**
- 우수리: 빵값을 내고 거슬러 받은 ___ 동전을 저금통에 넣었다. → **우수리**
- 어림: 도서관 책장을 ___으로 헤아려 보니 동화책이 백 권은 넘을 것 같았다. → **어림**
- 아름: 마을 앞 느티나무는 둘레가 두 ___이 넘는다. → **아름**
- 바리바리: 할머니가 김치며 떡이며 ___ 챙겨 주셔서 가방이 무거웠다. → **바리바리**
- 옹골지다: 올해 캔 감자는 하나하나 묵직하고 단단해서 참 ___. → **옹골지다**
- 가뜬하다: 무거운 책가방을 사물함에 두고 오니 어깨가 ___. → **가뜬하다**
- 되레: 동생을 놀리다가 ___ 내가 엄마한테 꾸중을 들었다. → **되레**

**3막 윤슬내**

- 윤슬: 바다에 아침 햇살이 비치자 ___이 눈부시게 일렁였다. → **윤슬**
- 볕뉘: 창고 판자 틈새로 ___가 비쳐 어두운 바닥이 조금 밝아졌다. → **볕뉘**
- 여우비: 햇볕이 나 있는데 ___가 오락가락해서 빨래를 걷을지 망설였다. → **여우비**
- 는개: 안개인 줄 알았는데 손등이 젖는 걸 보니 ___였다. → **는개**
- 함초롬하다: 머리를 감아 물기가 촉촉한 동생 머리카락이 ___. → **함초롬하다**
- 시나브로: 해가 지는 줄도 모르게 ___ 날이 어두워졌다. → **시나브로**
- 가뭇없다: 눈 깜짝할 사이에 지우개가 ___ 사라져서 아무리 찾아도 보이지 않았다. → **가뭇없이**
- 아스라하다: 할아버지의 어린 시절 이야기는 ___ 옛날 일처럼 들렸다. → **아스라한**
- 그루터기: 등산하다 지친 우리는 ___에 걸터앉아 물을 마셨다. → **그루터기**
- 물꼬: 서로 말이 없던 두 반이 반장의 농담 한마디로 대화의 ___를 텄다. → **물꼬**

**4막 안개 고개**

- 너나들이: 캠프에서 처음 만난 아이들과 사흘 만에 ___하며 지내게 되었다. → **너나들이**
- 살갑다: 이웃집 형은 만날 때마다 반갑게 인사해 주어 참 ___. → **살갑다**
- 데면데면하다: 오랜만에 만난 친구가 반가운 기색 없이 ___ 대해서 서운했다. → **데면데면하게**
- 서름하다: 이사 온 옆집 아이와는 인사만 나눈 사이라 아직 ___. → **서름하다**
- 새치름하다: 칭찬을 받고도 시치미를 떼며 ___ 앉아 있는 짝꿍이 귀여웠다. → **새치름하게**
- 마뜩잖다: 엄마는 내가 고른 옷이 ___ 표정이었다. → **마뜩잖은**
- 시샘: 옆 반이 줄다리기에서 이기자 우리 반 몇몇이 ___을 했다. → **시샘**
- 부아: 술래잡기에서 친구가 자꾸 반칙을 해서 ___가 났다. → **부아**
- 애꿎다: 짝꿍이 떠든 탓에 ___ 우리 모둠까지 남아서 청소를 했다. → **애꿎은**
- 다독이다: 시험을 망쳐 우는 친구의 어깨를 가만히 ___. → **다독였다**

**5막 잿빛 탑**

- 다부지다: 우리 반 주장은 몸집은 작아도 끝까지 버티는 ___ 아이다. → **다부진**
- 미쁘다: 약속을 한 번도 어기지 않는 반장은 참 ___. → **미쁘다**
- 애오라지: 수학 시험이 끝날 때까지 ___ 문제 푸는 데만 마음을 모았다. → **애오라지**
- 내처: 공원을 한 바퀴 뛴 김에 ___ 학교 운동장까지 달려갔다. → **내처**
- 나래: 꿈을 향해 ___를 활짝 펴라는 선생님 말씀이 떠올랐다. → **나래**
- 웅숭깊다: 할머니는 마음이 바다처럼 ___ 분이라 누구의 실수도 너그럽게 감싸 주신다. → **웅숭깊은**
- 너울가지: ___가 좋은 삼촌은 처음 간 캠핑장에서도 이웃과 금세 어울렸다. → **너울가지**
- 늘품: 감독님은 그 선수가 아직 어려도 ___이 있다고 칭찬하셨다. → **늘품**
- 매조지다: 마지막 한 골을 넣어 결승전을 깔끔하게 ___. → **매조졌다**
- 도담도담: 동생은 첫돌이 될 때까지 감기 한 번 없이 ___ 자랐다. → **도담도담**
