# 2~5막과 엔딩 (임시 그림) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 1막부터 2~5막을 지나 엔딩(마지막 말 → 말빛 주머니 50장 → 만든 이)까지 임시 그림으로 끝까지 플레이할 수 있게 만들고, 설계 9절의 검사를 모두 단위·화면 검사로 고정한다.

**Architecture:** 막 데이터(`data/acts/act2.js`~`act5.js`, `data/ending.js`, `data/world.js`)는 설계 문서의 코드 묶음을 줄 범위 그대로 옮긴다. 규칙은 `js/rules/*.js` 순수 함수로 더하고(막 넘어가기, 보이는 인물, 동료 대사, 보스 뒤 장면, 세계 지도 표시), 화면(`js/scenes/worldmap.js`, `js/scenes/ending.js`, 탐험·대화·전투·클리어 장면 고침)은 상태를 읽고 규칙을 부르기만 한다. 먼저 모든 막을 도는 데이터 검사를 만들고 데이터를 넣은 뒤, 진짜 데이터로 규칙과 화면을 검사하며 만든다.

**Tech Stack:** HTML, CSS, 순수 JS 모듈(ES2022, 빌드 없음), Node 22 `node --test`, Playwright 1.56.1, GitHub Actions(`test.yml`, `pages.yml`), GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-04-acts2-5-design.md` 2·3·5·6·8·9절과 10절 1~3·5(이하 "설계"). 기준 설계 `docs/superpowers/specs/2026-11-04-woorimal-rpg-design.md`. 바로 앞 계획 `docs/superpowers/plans/2026-11-04-stay-after-victory-and-hidden-reveal.md`(출구, `revealedBy`, `revealed`, `bossGone`, `__test.patchState`, `walkToExit`)는 이미 끝났고 그 코드 위에 얹는다.

**이 계획에 넣지 않는 것:** 그림 만들기(설계 7절, 10절 4)는 다음 계획이다. 이번에는 `data/assets.js`에 2~5막·엔딩·세계 지도 경로 칸을 모두 `null`로만 만들고, 지금 있는 임시 그림(색 블록, 그라데이션, 이름 첫 글자)으로 보이게 한다. Vercel 배포(설계 10절 6)는 하지 않는다(아래 Global Constraints).

## Global Constraints

- 배포는 **GitHub Pages**다: `.github/workflows/pages.yml`이 `main`과 `claude/gracious-thompson-8cti4h`에 push될 때마다 `npm test`를 돌린 뒤 `index.html`, `css/`, `js/`, `data/`, `assets/`만 `gh-pages`로 올린다(`https://989-alt.github.io/woorimal-rpg/`). 설계 10절 6의 "Vercel에 배포"는 이것으로 바꾼다. 워크플로는 고치지 않는다.
- 사이트가 `/woorimal-rpg/` 아래에서 열리므로 `js/`·`css/`·`data/`의 경로는 모두 상대 경로다(맨 앞 `/` 금지). `npm test`가 실패하면 배포되지 않는다.
- 정적 웹앱, 빌드 없음, 서버·로그인·소리 없음, 외부 런타임 라이브러리 없음. 기존 게임의 이름·인물·그림·화면을 흉내 내지 않는다.
- 규칙은 `js/rules/*.js` 순수 함수(받은 상태를 바꾸지 않고 새 상태를 돌려준다), 내용(낱말·대사·퀘스트·맵·지도 자리)은 `data/`에만 둔다.
- **데이터는 설계 코드 묶음을 글자 하나 바꾸지 않고 옮긴다.** 대사를 다시 쓰거나 다듬지 않는다. 옮길 줄 범위(설계 파일, 코드 울타리 안쪽): 2막 178–606, 3막 641–1072, 4막 1106–1556, 5막 1590–2012, 엔딩 2059–2129. 유일한 덧붙임: 엔딩 4번째 장면 객체에 `still: true`(설계 6절 표와 8절 8). 계획을 쓸 때 이 범위를 뽑아 9절 1~12 검사를 돌려 보았고 모두 통과했다. 옮긴 뒤 검사가 실패하면 옮겨 적기 잘못이므로 `diff`로 설계와 견주어 고치고, 글을 고쳐 검사를 맞추지 않는다.
- 저장 형식 `version: 1` 그대로. 새 필드 `seenScenes`(배열)·`revealed`(객체)는 없으면 빈 것으로 보고 `SHAPE`에 넣지 않는다.
- 대표색은 주인공 `#3B5BA5`, 도담 `#8E4A7A`, 해솔 `#F08A3C`, 나래 `#A9C9D6`만 쓴다. 말빛 금 `#F2C14E`은 낱말·정답 띠와 테두리에만(글자색 금지). 세계 지도 표시·출구는 놋쇠(`--brass` `#C9963F`)·흰빛·잿빛(`#8A8D91`). 나래 빛 모습 색은 `#9FD3E8`.
- 글꼴: 대사·UI 고운돋움(`--font-body`), 제목 주아(`--font-title`). 글자 18px 이상, 누르는 것 48×48px 이상, 초점 고리는 지금 `:focus-visible` 규칙 그대로. 주아에 없는 `「」`는 `font-family: var(--font-body)`인 `<span>`에 넣는다(`tests/fonts.test.mjs`의 FALLBACK_OK 규칙).
- 움직임은 `prefers-reduced-motion: reduce`면 바로 끝난 모습으로(세계 지도 걷기, 50장 켜짐, 숄 밝힘).
- 장면 뿌리 `<section>`은 클래스 `end-scene`을 함께 단다(`tests/css.test.mjs`의 `position: fixed; inset: 0` 규칙을 그대로 받는다).
- 새 그림 경로 칸은 모두 `null`. `ASSETS.busts[id]`의 키는 설계 인물 표의 "표정" 칸 그대로(모두 `null`).
- 한글 글자를 `data/`·`js/`·`css/`·`index.html`에 더한 작업은 마지막 검사 전에 글꼴 서브셋을 다시 만들고 `assets/fonts/*.woff2`, `tools/fonts/*.chars.txt`를 함께 커밋한다: `/root/.local/share/sprite-gen/.venv/bin/python -I tools/subset-fonts.py --gowun design/art/ui/raw/fonts-dl-gowun/GowunDodum-Regular.ttf --jua design/art/ui/raw/fonts-dl-jua/Jua-Regular.ttf --out assets/fonts --chars-out tools/fonts`
- 검사용 도움 기능은 `?test=1`일 때만 `window.__test`로 드러난다.
- 모든 작업은 끝날 때 `npm test`가 통과하고, 화면을 고친 작업은 `npm run test:e2e`도 통과한다.
