# 말빛 한울 (가제)

초등학교 6학년이 고유어(순우리말) 50개를 이야기 속에서 만나고 익히는 웹 RPG입니다.
마을을 걸어 다니며 사람들의 말 속에서 낱말을 모으고, 모은 낱말로 잿빛 그림자와 턴제 퀴즈 전투를 합니다.

- 설계 문서: `docs/superpowers/specs/2026-11-04-woorimal-rpg-design.md`
- 게임 주소: https://989-alt.github.io/woorimal-rpg/

## 선생님께: 저장과 기기 안내

- **저장은 그 기기의 그 브라우저에만 남습니다.** 게임은 학생이 처음에 적은 **이름(닉네임)** 별로 진행을 저장합니다. 서버나 로그인이 없어서, 같은 기기·같은 브라우저·같은 주소(위 게임 주소)로 열어야 이어 할 수 있습니다.
- **시크릿 창(비공개 창)이나 게스트 모드로 열지 마세요.** 창을 닫으면 저장이 지워집니다.
- **매번 같은 기기, 같은 브라우저를 쓰게 해 주세요.** 다른 기기나 다른 브라우저에서는 저장이 보이지 않습니다. 브라우저의 방문 기록·사이트 데이터를 지워도 저장이 없어집니다.
- **이름을 똑같이 적어야 합니다.** "이어하기"에서 처음에 적은 이름을 고르면 그 이름의 진행이 이어집니다. 한 기기를 여러 학생이 함께 쓸 때는 저마다 다른 이름을 적게 해 주세요.
- **전체 화면:** 태블릿·휴대폰에서는 처음 화면을 누르면 전체 화면이 켜집니다(되는 브라우저만). 화면 위의 전체 화면 단추나 F 키로도 켜고 끌 수 있습니다.
- **아이폰·아이패드 사파리:** 전체 화면이 되지 않으므로 공유 단추에서 **"홈 화면에 추가"** 를 누른 뒤, 홈 화면의 아이콘으로 열어 주세요. 홈 화면 아이콘으로 연 게임은 사파리와 저장이 따로일 수 있으니 한쪽으로만 여세요.
- **기기는 가로로 들고** 하게 해 주세요. 세로로 들면 화면이 좁아 글과 단추가 작아집니다.
